# Agent Guidelines & User Preferences

## Strict Punctuation & Style Rule: NO DASHES
* NEVER use dashes of any kind in anything:
  * No em dashes (—)
  * No en dashes (–)
  * No hyphens used as clause separators ( - or -- )
* In prose, UI copy, labels, documentation, README files, commit messages, comments, and conversation responses:
  * Use periods, commas, colons, semicolons, or parentheses instead of dashes.
  * When describing ranges, use words like "to" or "through" (for example, "10 to 12 cm", "0.8 to 0.9", "September to November").
  * For lists, use asterisks (*) or numbered lists rather than hyphens.
